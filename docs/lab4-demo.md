# ЛР4: сценарій показу

Запуск: `docker compose up --build`, потім `scripts\seed-demo.ps1` (демо-користувач `anna@miniproject.local`).
Клієнт: http://localhost:8080. Шлюз: http://localhost:5000.

## Живе демо (≈4 хв)
1. **Вхід і каталог** — видно скелетони; пошук спрацьовує через 400 мс після останнього символа (debounce).
2. **Деталі** — складений запит `GET /api/v1/screens/training/{id}`; зупинити Schedule (`docker compose stop schedule`) → екран показує попередження, а не падає (`partial`).
3. **Запис** — подвійний клік дає один запис; у DevTools видно один `Idempotency-Key`, повтор → `Idempotency-Replayed: true`.
4. **Мої записи** — скасування запису; помилки по полях показані під полем.
5. **429** — серія швидких запитів → банер з паузою за `Retry-After`.
6. **401** — прибрати access-токен у localStorage → тихе оновлення токена й повтор запиту.
7. Темна тема; офлайн (DevTools → Offline) — список каталогу з кешу.

## Чекліст для викладача
| Вимога | Де показати |
|---|---|
| 5 екранів, 4 стани | пп. 1–4 |
| Єдиний шар API | `client/js/api/` |
| 401 / 429 / деградація / таймаути | пп. 2, 5, 6 |
| Помилки по полях | форма запису з невалідним workoutId |
| Idempotency-Key + подвійний клік | п. 3 |
| Без userId/секретів/адрес сервісів у клієнті | `grep -ri "secret\|:500[1-9]" client/js` — порожньо |
| Складений запит для деталей | п. 2 |
| Презентація 5–8 слайдів | окремий файл |
| Бонус: docker-compose усього стеку | `docker compose up --build` |
